# The Cake of English Tenses — интерактивная книга

Электронная версия книги «The Cake of English Tenses: 12 Tenses — One Amazing System!»
(Надопта Олеся Владимировна): открывается по ссылке в браузере, листается как настоящая —
с перелистыванием страниц, увеличением и полноэкранным режимом. Работает и на компьютере,
и на телефоне (Android, iPhone), и без интернета.

Готовый PDF наружу не отдаётся: страницы уже разложены на картинки, поэтому книга
открывается мгновенно и не зависит от сторонних сервисов.

## Как открыть

- **Проще всего:** двойной клик по `index.html` — книга откроется в браузере.
- **Как на сервере** (так же, как она будет выглядеть по ссылке):

  ```powershell
  .\serve.ps1
  ```

  Скрипт напечатает адрес `http://localhost:8080` и адрес в локальной сети — по нему
  книгу можно открыть с телефона, если он в той же сети. Это лучший способ проверить,
  как книга ведёт себя на реальном телефоне.

## Управление

**На компьютере (мышь и клавиатура)**

- Листать: клик по правой половине страницы — вперёд, по левой — назад; перетаскивание
  страницы за уголок; кнопки ‹ › по бокам; колесо мыши; клавиши `←` `→` `Пробел` `PageUp` `PageDown`.
- Увеличить: кнопки с лупой, клавиши `+` и `−`; в увеличенном виде страницу можно таскать
  мышью. `0` или `Esc` — вернуть 100 %.
- Во весь экран: кнопка в правом верхнем углу или `F`.
- Все страницы: кнопка-сетка или `T` — панель справа. В ней книга показана так же,
  как листается: обложка отдельно, дальше разворотами (2–3, 4–5, … 40–41).
  Клик по развороту открывает его первую страницу.
- Спрятать интерфейс и читать «чисто»: клавиша `H` (или `Esc`, когда нечего закрывать).
- `Home` / `End` — в начало и в конец книги.

**На телефоне (касания)**

- Листать: свайп — страница оттягивается за пальцем и переворачивается, если жест
  достаточно быстрый или длинный; короткое движение возвращает страницу назад.
  Свайп работает и по пустому полю вокруг книги, не только по самой странице.
- Листать: касание у правого или левого края страницы.
- Касание по узкой полосе в центре — спрятать или показать панели (удобно читать
  на маленьком экране). Тап-зоны специально совпадают с тем, как книга
  листается мышью на компьютере.
- Увеличить: **щипок двумя пальцами** (без ограничений по кнопкам), в увеличенном виде
  страница двигается одним пальцем. Кнопка-чип внизу возвращает 100 %.
- Боковых стрелок и кнопок увеличения на телефоне нет — там всё делается жестами,
  а кнопки внизу сделаны крупными, под палец (не меньше 44 px).

**Ссылка на конкретную страницу.** Кнопка-цепочка копирует адрес вида `...#p=12`:
у получателя книга откроется сразу на 12-й странице. Удобно отправлять жюри или коллегам.

## Что внутри

```
flipbook/
├── index.html                    — сама книга (открывать этот файл)
├── serve.ps1                     — локальный сервер в одну команду
├── assets/
│   ├── style.css                 — оформление: фон, корешок, панели, мобильная раскладка
│   ├── app.js                    — листание, жесты, масштаб, ссылки на страницы
│   └── vendor/                   — StPageFlip 2.0.7 (MIT) — эффект перелистывания
├── pages/p001..p041.webp         — страницы книги, 1400×2010, WebP качество 92
├── thumbs/p001..p041.webp        — миниатюры для панели разворотов
└── tools/                        — сборка и проверки (в публикацию не нужны)
    ├── build-assets.py           — пересборка страниц из PDF
    ├── run-checks.ps1            — все проверки одной командой
    ├── verify.mjs                — сценарии на компьютере, мышь и клавиатура
    ├── verify-mobile.mjs         — телефонные профили и тач-жесты
    ├── verify-regressions.mjs    — проверки на каждый найденный дефект
    ├── verify-assets.py          — сверка страниц с PDF
    ├── compare-quality.py       — подбор качества сжатия страниц
    ├── compare-screenshots.py    — сверка экрана со страницами
    ├── check-visuals.py          — проверка композиции снимков
    └── _checks/                  — скриншоты последней проверки
```

Вес книги — около 34 МБ (страницы 32 МБ + миниатюры 2 МБ). Страницы подгружаются
по мере листания: рядом с текущей страницей держится небольшое окно (около десяти
страниц), а дальние отпускаются, чтобы телефон не держал в памяти полтысячи мегабайт
картинок. Первая страница показывается сразу, остальное докачивается в фоне.

## Известные компромиссы

- **Зум браузера на телефоне отключён** (`user-scalable=no` в `index.html`): иначе
  собственный щипок книги работает плохо, а браузер зумит всю страницу вместе с панелями.
  Увеличение самой книги при этом работает всегда — щипком, двойным тапом по кнопке
  масштаба и колесом мыши на компьютере. На компьютере браузерный зум (Ctrl + колесо)
  не перехватывается и работает как обычно.
- **Если страница не загрузилась**, книга делает три попытки с нарастающей паузой,
  потом показывает на странице пометку «Страница не загрузилась». При переходе на такую
  страницу заново загрузка повторяется. Остальная книга при этом работает.
- **Дальние страницы выгружаются из памяти.** Если быстро проскочить десяток страниц
  и вернуться, страница может на миг показаться размытой, пока подтягивается картинка.
- **Пропорции страниц точно совпадают с макетом** (1400×2010 = 700×1005), поэтому
  зритель не обрезает ни одного пикселя. Сами файлы JPEG-подобного формата WebP
  сжаты с качеством 92 — выше были видны артефакты на тексте.

## Как проверить, что всё живо

```powershell
.\tools\run-checks.ps1
```

Скрипт поднимает локальный сервер, открывает headless Chrome и прогоняет:
сценарии на компьютере (в том числе мышь), пять телефонных профилей (iPhone, Pixel,
маленький телефон, альбомная ориентация), тач-жесты (свайп, короткий свайп, щипок,
тап), регрессии по код-ревью (память, сбойная страница, доступность, свайп по пустому
полю), сверку каждой страницы на экране с исходным PDF и проверку композиции снимков.
Скриншоты складываются в `tools\_checks\`.

Перед запуском скрипт проверяет, что порт свободен, что сервер отдаёт именно те файлы,
что лежат на диске, и стартует браузер с чистым кэшем — иначе прогон мог бы показать
зелёный результат на прошлой версии файлов.

## Как выложить по ссылке

Папка `flipbook` — обычный статический сайт; в публикацию нужны только `index.html`,
`assets/`, `pages/` и `thumbs/` (папку `tools` можно не загружать).

- **Netlify Drop** — <https://app.netlify.com/drop>: перетащить папку в окно браузера,
  через минуту появится ссылка. Быстрее всего, регистрация бесплатная.
- **GitHub Pages** — если ссылка нужна надолго: публичный репозиторий, содержимое папки,
  в *Settings → Pages* выбрать ветку `main` и папку `/ (root)`.
- **Cloudflare Pages** — то же самое, тоже бесплатно.

Яндекс.Диск, Google Drive и файлообменники не подойдут: они не открывают HTML как сайт —
файл просто скачается. Для показа без хостинга можно открыть `index.html` локально
или показать с телефона через `serve.ps1`.

## Если книга обновится

Положите новый PDF рядом с папкой `flipbook` и запустите:

```powershell
py -3 tools/build-assets.py
```

Скрипт заново нарежет страницы в `pages/` и `thumbs/`. Если число страниц изменится,
поправьте `TOTAL` в начале `assets/app.js` (и там же `SPREADS` соберётся сам).
Нужные библиотеки ставятся один раз:

```powershell
py -3 -m pip install pymupdf pillow
```
